# 6AM — NÃO DEIXE ENTRAR (V2)

Jogo de terror pixel art feito em HTML5 Canvas + JavaScript puro. Não precisa de Godot, Node ou servidor.

## Jogar localmente
Abra `index.html` no navegador.

## Publicar no GitHub Pages
1. Crie um repositório.
2. Envie `index.html`, `style.css` e `game.js` (e os arquivos opcionais).
3. Em **Settings → Pages**, escolha a branch `main` e a pasta `/root`.
4. Abra o endereço do GitHub Pages.

## Controles
- WASD / setas: mover
- E: reparar/reforçar a entrada próxima
- F: lanterna
- Q: observar (segura)
- P: pausa
- Enter: iniciar
- R: reiniciar depois de morte/final

## Ideia da V2
Você é uma criança sozinha em casa das 22:00 às 06:00. O Baphomet muda de forma ao longo da noite e aprende quais entradas você deixa sem atenção. As formas possuem comportamentos distintos, e o terror depende tanto de informação visual quanto de sons e distrações.
