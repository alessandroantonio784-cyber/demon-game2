# 6AM — Não Deixe Entrar

Um jogo de terror pixel art inspirado em um sonho: uma criança fica sozinha em casa enquanto uma criatura chamada Baphomet tenta entrar antes das 06:00.

## Como jogar

Abra `index.html` em um navegador moderno.

**Controles**
- `W A S D` / setas — movimentar
- `E` ou `Espaço` — reforçar a entrada mais próxima
- `F` — ligar/desligar a lanterna
- `P` — pausar
- `R` — reiniciar depois de morrer ou vencer

## Mecânicas

- Sobreviva das 22:00 às 06:00.
- Existem seis portas/janelas para manter protegidas.
- O nível de cada tranca cai conforme a criatura estuda seus hábitos.
- O Baphomet muda de forma durante a noite:
  - **Cão Negro**: cria sons falsos dentro da casa.
  - **Pantera**: interfere na iluminação e usa a escuridão.
  - **Lobo**: enfraquece várias trancas ao mesmo tempo.
  - **Baphomet**: aprende a rotina e pode manipular trancas ou imitar uma voz.
- A lanterna ajuda a enxergar, mas a bateria é limitada.
- Há cutscene de abertura, morte com gore pixelizado leve e final de sobrevivência.

## GitHub Pages

1. Crie um repositório.
2. Envie todos os arquivos desta pasta.
3. Nas configurações do GitHub, ative **Pages** usando a branch principal e a pasta raiz.
4. Abra o endereço gerado pelo GitHub Pages.

O jogo não usa assets externos nem dependências de npm.
